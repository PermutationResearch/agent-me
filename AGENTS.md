# Agent-Me

Agent-Me helps people extract, review, and export their AI-agent traces and improve their agent setup. Read `README.md`, `ROADMAP.md`, and the relevant project documentation before changing behavior; do not confuse planned capabilities with implemented ones.

- Frontend: `frontend/`; backend: `backend/`; MCP integration: `mcp/`; product and architecture docs: `docs/`.
- Trace review and export are described in `docs/TRACES.md`; submission and private review in `docs/SUBMISSIONS.md`.
- `Makefile` documents `make test`, `make lint`, `make docs`, and `make evaluate`. Check prerequisites and run checks appropriate to the change; report what ran.
- Treat traces, archives, and `private/` as potentially sensitive. Follow the project's consent and selection flows; do not upload, sell, expose, or promote private history without authorization.

If `AGENTS.local.md` exists, read it too. It holds machine-specific notes and is never committed.
